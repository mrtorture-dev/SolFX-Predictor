# SolFX-Predictor: Predicción del tipo de cambio USD/PEN mediante Machine Learning

## Resumen
El presente trabajo plantea un sistema de aprendizaje supervisado para pronosticar la cotización del dólar en soles a uno, cinco y veinte días hábiles con el fin de solucionar el problema originado por las fluctuaciones actuales del tipo de cambio monetario que dificultan la planificación financiera y la gestión del riesgo cambiario en el Perú. La propuesta combina diversos datos históricos, indicadores económicos, rezagos y estadísticas móviles, para comparar regresiones regularizadas con ensambles de árboles.
